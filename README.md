# AI NEWS

Google ニュースのRSSから、AI関連ニュースをカテゴリ別に表示する日本語Webアプリです。追加のAPIキーや外部Pythonパッケージは必要ありません。

## 起動方法

Python 3.10以降をインストールし、このフォルダーで次を実行してください。

```powershell
python server.py
```

パソコンでは <http://127.0.0.1:8000> を開きます。終了するにはターミナルで `Ctrl+C` を押してください。

## GitHub Pagesで公開する

このリポジトリをGitHubへpushすると、GitHub Actionsが5カテゴリのニュースを取得して静的サイトを作成し、GitHub Pagesにデプロイします。ニュースは毎時17分・47分ごろにも自動更新されます（GitHub Actionsの実行状況により前後します）。Actionsタブから手動実行もできます。

GitHubリポジトリの Settings → Pages を開き、Build and deployment の Source を「GitHub Actions」に設定してください。初回デプロイ完了後に表示されるPagesのHTTPS URLをiPhoneのSafariで開き、共有ボタンから「ホーム画面に追加」を選びます。

GitHub PagesではPythonサーバーを実行できないため、`build_site.py` が生成した `news.json` を画面から読み込みます。キーワード検索は取得済み見出しと配信元を対象にします。

## iPhoneで使う

PagesのHTTPS URLをSafariで開き、「共有」→「ホーム画面に追加」を選ぶとアプリ風の全画面表示で起動できます。初回にオンラインで読み込むとアプリ画面と最後に取得したニュースが保存され、オフライン時にも表示できます。新しいニュースの取得と記事を開く操作にはインターネット接続が必要です。

## ローカルで起動する

Python 3.10以降をインストールし、このフォルダーで `python server.py` を実行してから <http://127.0.0.1:8000> を開きます。ローカル起動では従来どおりGoogleニュースRSSから検索結果をライブ取得します。終了するにはターミナルで `Ctrl+C` を押してください。

## 機能

- すべて、生成AI、ビジネス、研究・テクノロジー、日本のAIのカテゴリ切り替え
- 日本語キーワード検索と手動更新（Pages版は取得済みニュース内を検索）
- ニュース配信元、公開時刻、記事リンクの表示
- 取得結果を3分間キャッシュして、外部RSSへの連続リクエストを抑制
- iPhoneのホーム画面へ追加できるPWAとオフライン用キャッシュ
- GitHub Actionsによる30分ごとのニュース取得とPagesデプロイ

ニュースの取得にはインターネット接続が必要です。
